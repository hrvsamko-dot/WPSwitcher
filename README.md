# WPSwitcher

Hi this is my first project. I wanted to make a simple wallpaper switcher because, i didnt like my ruff switcher. Mine isnt perfect but its pretty quick and still nice. I made it using  customtkinter so yeah nothing special. I made it for my arch linux setup so it works only on linux with the right stuff. It comes with a few default wallpapers so u can enjoy. its compatible with hyprland, so it wont be resized and i plan to add classes, when i learn them. Feel free to use this as basic customtkinter and pillow learning material.

# dependecies
"""
sudo pacman -S customtkinter pillow awww
"""

# other requirements
