# WPSwitcher

Hi this is my first project. I wanted to make a simple wallpaper switcher because, i didnt like my ruff switcher. Mine isnt perfect but its pretty quick and still nice. I made it using  customtkinter so yeah nothing special. I made it for my arch linux setup so it works only on linux with the right stuff. It comes with a few default wallpapers so u can enjoy. i still have to patch the compatibility with hyprland and i also want to add classes once i learn them.
